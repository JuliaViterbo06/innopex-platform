Fontes e metodologia

Como os números desta tela são produzidos, em linguagem de negócio.

De onde vêm os dados

Duas fontes oficiais alimentam a plataforma, sem digitação paralela:

  • OpEx Global — lista Projects do SharePoint corporativo, usada por toda a GM. Dela vêm charter, metodologia, aprovações, impactos financeiros por ano e as datas ECD de cada fase DMAIC.
  • Growth Project (local GMSA) — lista do site Growth Projects Management. Dela vêm Horizonte, Blue/Green Value, fases de inovação, Core Team, InnOpEx Master e Meeting Notes.

A carga roda uma vez por dia (e sob demanda) em um job do Databricks, filtrando apenas registros GMSA. A plataforma nunca é fonte primária de dados financeiros: ela lê, consolida e devolve as alterações de governança para o SharePoint de origem.

Desenvolvimento: os números são ilustrativos (modo mock). Os dados ficam em data/state.json; nada é gravado no SharePoint nem enviado por e-mail.

Ver consulta de exemplo (Databricks SQL) 
SELECT p.project_id, p.name, p.project_type, p.phase, p.master,
       p.blue_value_musd, p.last_update, p.next_review
FROM   innopex.silver.projects p
WHERE  p.region = 'GMSA'
  AND  p.is_active
ORDER BY p.phase, p.blue_value_musd DESC;
